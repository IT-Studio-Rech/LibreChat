# Document Templates

This directory contains DOCX template files used by the `/api/agents/generate-document` endpoint to produce client-ready offer and contract documents.

## Files

| File | Purpose |
|---|---|
| `offer-placeholder.docx` | Angebot / Offer template |
| `contract-placeholder.docx` | Vertrag / Contract template |
| `generate-placeholders.js` | Script to regenerate placeholder DOCX files |

## TARA-CONTENT-SLOT

The current files are **placeholders** generated by `generate-placeholders.js`. They are structurally valid DOCX files that demonstrate placeholder syntax, but they carry no real branding or design.

**Tara replaces these files** with her final branded DOCX templates (correct fonts, logo, layout). The file names must stay identical (`offer-placeholder.docx`, `contract-placeholder.docx`).

### How to update

1. Open the file in Word / LibreOffice Writer.
2. Apply the final design (branding, fonts, logo).
3. Insert docxtemplater placeholders where dynamic content should appear (see table below).
4. Save as `.docx` (Word format) with the same filename.
5. Drop the file into this directory — the server picks it up immediately (no rebuild needed).

## Placeholder variables

Placeholders follow docxtemplater syntax: `{variable_name}`.

### Offer (`offer-placeholder.docx`)

| Placeholder | Description |
|---|---|
| `{client_name}` | Full name of the client |
| `{client_email}` | Client e-mail address |
| `{offer_date}` | Date of the offer (formatted string) |
| `{services}` | Description of services offered |
| `{price}` | Total price / fee |
| `{notes}` | Optional remarks |

### Contract (`contract-placeholder.docx`)

| Placeholder | Description |
|---|---|
| `{client_name}` | Full name of the client |
| `{client_email}` | Client e-mail address |
| `{contract_date}` | Contract signing date (formatted string) |
| `{contract_text}` | Full body / subject of the contract |
| `{services}` | Contracted services |
| `{price}` | Agreed fee |
| `{signature_placeholder}` | Placeholder for the signature block |

## Regenerating the placeholder files

If the placeholder DOCX files need to be recreated from scratch (e.g. after a `git clean`):

```bash
# From the repo root — PizZip must be installed in packages/api
cd packages/api && npm install
cd ../..
node templates/generate-placeholders.js
```

## API usage

```http
POST /api/agents/generate-document
Content-Type: application/json
Authorization: Bearer <token>

{
  "template": "offer",
  "data": {
    "client_name": "Lisa Müller",
    "client_email": "lisa@example.com",
    "offer_date": "08.05.2026",
    "services": "Brand Coaching, 3 Sessions",
    "price": "€ 1.200,00",
    "notes": ""
  },
  "format": "pdf"
}
```

Response:

```json
{
  "file_id": "...",
  "filename": "offer-<uuid>.pdf",
  "type": "application/pdf",
  "source": "local",
  "filepath": "..."
}
```

`format` can be `"pdf"` (requires LibreOffice + `OFFICE_PREVIEW_LIBREOFFICE=true`) or `"docx"` (always available).
